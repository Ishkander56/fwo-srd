# FWO System Reference Document

This is an online reference for Filled With Online (original work by [Project FW](http://projectfw.web.fc2.com), translation by [Ishkander](https://github.com/ishkander56)). This site has been built using [Coweater's RPG SRD Template](https://github.com/7thExtinctionrpg/RPG_SRD_Template), powered by [Docsify](https://docsify.js.org/).



Filled With Online is a free indie RPG, first existing as "GURPS Filled With" for GURPS 3e in 2012, set in a VR MMORPG (*virtual-reality massively-multiplayer online role-playing game*) populated by Deep Learning AI characters, taking up their own defense against demonkind after the disappearance of their heroes.
